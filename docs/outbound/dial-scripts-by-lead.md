# Personalized Dial Scripts by Lead

Custom call openers built for specific leads on the floor. Each script is tailored to the
prospect's vertical and situation. Use these verbatim or adapt to the conversation.

Standard structure: opener with name check, pause for recognition, branch on whether they
remember, 2-minute demo pitch, close with price.
