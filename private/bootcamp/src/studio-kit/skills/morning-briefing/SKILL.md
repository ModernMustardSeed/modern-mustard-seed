# The Morning Briefing

Fifteen minutes a day is the whole management job when a crew runs the
business. The briefing is what makes fifteen minutes enough.

## Gather

Read, do not guess. Each line in the briefing has a source.

1. **Overnight.** Every scheduled job: did it run, how long, did it finish.
   A job that did not report is a failure until proven otherwise.
2. **Shipped.** Merged pull requests and live changes since yesterday's
   briefing, each checked on the live address.
3. **Inbox.** Customer emails, form fills, missed calls and voicemails that
   need a human. Not newsletters.
4. **Money.** Payments received, payments failed, refunds, anything unusual.
5. **Decisions waiting.** Anything an agent stopped and asked about, and how
   long it has waited.

## Write

One screen. In this order:

1. **Three decisions for today**, each with the options and a recommendation.
2. **What broke**, each with what was done about it or what is needed.
3. **What shipped**, one line each, with the live link.
4. **The numbers**, compared with the same day last week.
5. **Three things worth doing today**, ordered.

No good news padding and no alarm without a next step. If nothing broke, say
"Nothing broke" in one line and move on.

## Done means

The owner can read it standing up and know exactly what to say yes to.
