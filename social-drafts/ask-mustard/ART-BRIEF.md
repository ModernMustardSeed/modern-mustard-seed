# The Column (Set eight · Ask Mustard) — spot illustration brief

Six woodcut newspaper spot illustrations, generated by Sarah in Codex (free)
instead of fal. The render script works without them and upgrades automatically
when a spot exists at `art/<key>.png`. Spots are black ink on pure white; the
renderer multiply-blends them onto the newsprint so the white disappears.

## Rules
- Generate all six in ONE chat session so the style stays consistent.
- **Absolutely no text, letters, numbers, words, or watermarks in the image.**
- Size: square **1024x1024**, single subject centered, wide margins, pure
  white background.
- Save as the exact filenames below, drop into `social-drafts/ask-mustard/art/`.

## Spots

| File | Column question | Subject |
|---|---|---|
| `01-every-day.png` | Do I have to post every day? | Stack of folded newspapers tied with twine |
| `02-tiktok.png` | Do I really need to be on TikTok? | Old tabletop TV with rabbit-ear antennas |
| `03-what-it-costs.png` | How much should a website cost? (never type a price) | Classic two-pan balance scale |
| `04-the-robot.png` | Is AI going to replace me? | Friendly vintage robot tipping a bowler hat |
| `05-the-gloves.png` | I want to fight a nasty review | Worn boxing gloves hanging from a nail |
| `06-slow-season.png` | Winter is dead, what now? | Paper seed packet with trowel and spilled seeds |

The Metro (set seven) needs NO generated art: the transit map is drawn in code.

Prompt template (self-contained, one per image):

> Vintage newspaper editorial spot illustration, hand-engraved woodcut style,
> pure black ink linework on a plain pure-white background, single subject
> centered with wide empty margins. [SUBJECT]. Absolutely no text, no letters,
> no numbers, no words, no watermark. Square.
