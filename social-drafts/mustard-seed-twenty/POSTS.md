# The Mustard Seed Twenty · Set thirteen · The Kingdom Trades

Twenty WPA style posters of the trades the Kingdom was told through, the faith
sister set to The Main Street Twenty. Core emotion: reverent belonging, faith
and work seen as one thing. The company is named for No. 20 (Matthew 13:31).
This file mirrors `data/social-cards.ts`. Edit both or neither.

## The campaign

- **Cadence:** one poster per weekday on our own Page for a month. In groups,
  only where faith content is welcome (church groups, faith and business
  groups, community groups that allow it). The faith set NEVER goes into a
  secular trade group; that is what set twelve is for.
- **The engine:** same giveaway. Whoever runs the trade (or the ministry)
  comments and gets the full resolution file free. Poster FIRST, then one soft
  line.
- **The church escalator:** a pastor or ministry leader who comments gets the
  WHOLE set free for the fellowship hall, church name set into the ink bar,
  also free.
- **Outbound:** never attach a faith poster to cold outreach. Only when their
  faith is public (their site or page says it) or they brought it up first.
  Email or live call only, never a cold text.
- **Scripture rails:** the reference on each card is real and checked. The
  honor line is OUR words, never a quotation. Asked for the verse, quote the
  passage accurately or link it. Never argue doctrine in a thread; the poster
  is a gift, not a debate.
- **Art rails:** no depiction of Jesus in any plate, ever. It is AI art, art
  directed at the studio, say so when asked. No prices anywhere.
