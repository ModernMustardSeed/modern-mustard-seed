# The Twelve Windows · Set fourteen · Scripture in Glass

Twelve KJV verses set in actual type over stained glass window plates, the
approved Cathedral Glass direction (study in `social-drafts/scripture-study/`,
Sarah picked it over The Broadside and Gold Illumination on 8/02). Nave dark
ground, EB Garamond italic verse, Marcellus gold reference. Core emotion: awe,
the verse lit from behind. This file mirrors `data/social-cards.ts`. Edit both
or neither.

## The campaign

- **Cadence:** one window every Sunday and Wednesday for six weeks, the church
  rhythm. Own Page always; groups only where faith content is welcome.
- **The engine:** the custom window. Comment the verse you live by and we set
  it in glass, free, full resolution. That request is the warmest lead this
  set produces and the promise is same day when possible.
- **The church escalator:** a pastor or ministry leader who comments gets all
  twelve for the building, church name set under the reference in gold, free.
- **Scripture rails:** the verse text is QUOTED EXACTLY, King James Version,
  marked KJV on every card. KJV because it is public domain, so the giveaway
  is truly unencumbered, and because it is beautiful. A custom window may
  carry the requester's preferred translation wording with its attribution
  when it is their personal copy. Never alter a word of the text beyond
  conventional partial quotation (04 and 11 quote the spoken clause).
- **Art rails:** symbolic glass only, no depiction of Jesus in any window.
  It is AI art directed at the studio, say so when asked. Never argue
  doctrine or translation in a thread. No prices anywhere.
